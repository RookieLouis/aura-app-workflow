# Aura app workflow

Codex skill and project instructions for maintaining the Aura desktop app and preparing reports or patches.

## Files

- `skills/aura-app-workflow/SKILL.md`: backup, reporting, packaging, and monthly archive rules.
- `skills/aura-app-workflow/agents/openai.yaml`: skill display metadata.
- `AGENTS.md`: tells the agent when to load the skill.

## Install

1. Copy `skills/aura-app-workflow` to `%USERPROFILE%\.codex\skills\aura-app-workflow`.
2. Copy `AGENTS.md` to the Aura app workspace root.
3. Update the Windows paths in `AGENTS.md` and `SKILL.md` for your machine. The committed paths reflect the original author's setup.
