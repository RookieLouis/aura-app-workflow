# Aura 应用工作约定

本仓库保存用于维护 Aura 桌面应用、制作报告和交付补丁的 Codex skill 与项目指令。

## 文件说明

- `skills/aura-app-workflow/SKILL.md`：备份、报告、交付打包和按月归档约定。
- `skills/aura-app-workflow/agents/openai.yaml`：skill 的显示信息。
- `AGENTS.md`：指示代理在处理 Aura 应用任务时按需读取 skill。

## 安装

1. 将 `skills/aura-app-workflow` 复制到 `%USERPROFILE%\.codex\skills\aura-app-workflow`。
2. 将 `AGENTS.md` 复制到 Aura 应用工作区根目录。
3. 根据自己的电脑修改 `AGENTS.md` 和 `SKILL.md` 中的 Windows 路径；仓库中的路径对应原作者的本地环境。
