# Aura 应用工作约定

仅在 Aura 桌面应用维护、界面修改、补丁交付或应用报告任务中读取本 skill。

## 维护与备份

- 本地工作区为 `D:\02 GameDev\Agent\Aura_app`。修改应用前核对实际安装位置与当前构建，避免复用过期的文件名或补丁定位。
- 涉及升级、覆盖文件或旧数据时，先备份受影响内容；Aura 应用相关备份统一保存到 `F:\Backup\Aura`。
- 调试与修复完成后默认简要反馈。只有用户明确要求报告时才制作图文报告。

## 报告与交付

- 报告默认使用中文。面向 Aura 开发者的最终报告使用英文，正文采用 Markdown 格式。
- 需要英文版时，先提供中文版供用户审阅；用户确认无需修改，或审阅后明确要求生成英文版，再制作英文版。已有确认不重复询问。
- 报告默认图文结合，按内容配上必要的截图、示意图或图表，并附文字说明。
- 将报告与直接相关的源码、补丁、测试、截图及说明文件一起打包，便于交接。

## 报告按月归档

- Aura 报告及配套输出统一保存到 `D:\02 GameDev\Agent\Aura_app\output\<月份>月\`。
- 月份按报告生成时的日期确定，时区使用 `Asia/Shanghai`，月份不补零。例如，10 月生成的报告归入 `output\10月\`。
- 对应月份目录不存在时先创建。
- 每份报告使用独立子目录，报告正文和配套文件放在其中；完整交付压缩包也保存在同一月份目录下。
